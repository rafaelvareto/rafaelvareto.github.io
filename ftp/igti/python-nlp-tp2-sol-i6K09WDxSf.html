TRABALHO PRÁTICO 2: Etiquetamento Gramatical com LSTM¶

Em aplicações linguísticas, Etiquetamento Gramatical (do inglês, Part-Of-Speech Tagging), também chamada de Marcação Morfológica, é o processo de marcar uma palavra em um texto (corpus) como correspondendo a uma classe gramatical específica, com base na sua definição e no seu contexto. Uma forma simplificada disso é comumente ensinada para crianças em idade escolar, na identificação de palavras como substantivos , verbos , adjetivos , advérbios , etc. Um exemplo de etiquetamento gramatical é dado na seção 2.4.1 da apostila da disciplina, que pode ser acessada através deste link.

Descrição dos Dados¶

Neste desafio, o objetivo é te introduzir de forma prática à tarefa de POS Tagging para a língua Portuguesa. Para isso utilizaremos o corpus Mac-Morpho, produzido pelo grupo NILC em da ICMC USP. O Mac-Morpho oferece dados para treinamento, validação e teste de modelos preditivos, capazes de classificar a classe gramatical de palavras em Português. Para acessar o conjunto de classes, acesse http://nilc.icmc.usp.br/macmorpho/macmorpho-manual.pdf.

Um exemplo da grasse gramatical ARTIGO pode ser visualizada abaixo:

  • O_ART patinho feio vivia chorando.
  • No meio do caminho havia uma_ART pedra.
  • Era uma_ART grande amiga.
  • As_ART folhas secas caíam no outono.
  • Os_ART alunos chegaram cedo.
  • Tinha uns_ART repentes interessantes.
  • Era um_ART homem de sorte.

O corpus da base de dados Mac-Morpho está disponível para download em http://nilc.icmc.usp.br/macmorpho/macmorpho-v3.tgz.

O mesmo encontra-se dividido em seções de treinamento, desenvolvimento e teste: o conjunto de treinamento corresponde a 76% da base de dados, o conjunto de desenvolvimento possui 4% do total de amostras enquanto o conjunto de teste representa 20%. A razão para os números incomuns é que o corpus foi inicialmente estruturado em 80% (treino) / 20% (teste) e, em seguida, 5% da seção do treino foi definida à parte para desenvolvimento. Essa divisão foi usada em muitos estudos, inclusive no artigo. Por esta razão, novas pesquisas de etiquetamento gramatical com Mac-Morpho são encorajadas a segui-la para tornar possíveis comparações consistentes.

def subset_splitter(data_subset, lower=False):
    data_tuples = list()
    for row in data_subset:
        if lower: row = row.lower()
        tuples_list = row.split()
        tuples_list = [element.split('_') for element in tuples_list]
        tokens_list = [token for (token, label) in tuples_list]
        labels_list = [label for (token, label) in tuples_list]
        data_tuples.append( (tokens_list,labels_list) )
    return data_tuples

def subset_categorizer(data_tuples):
    data_labels = set()
    data_tokens = set()
    for tokens,labels in data_tuples:
        data_labels.update(labels)
        data_tokens.update(tokens)
    return data_labels, data_tokens

def vocab_hist_counter(data_tuples, sort=False):
    label_hist = dict()
    vocab_hist = dict()
    for tokens, labels in data_tuples:
        for token in tokens:
            if token in vocab_hist: vocab_hist[token] += 1
            else: vocab_hist[token] = 1
        for label in labels:
            if label in label_hist: label_hist[label] += 1
            else: label_hist[label] = 1            
    if sort: 
        label_hist = sorted(label_hist.items(), key=lambda tup:tup[1], reverse=True)
        vocab_hist = sorted(vocab_hist.items(), key=lambda tup:tup[1], reverse=True)
    else:
        label_hist = list(label_hist.items()) 
        vocab_hist = list(vocab_hist.items())
    return label_hist, vocab_hist

Definição da Rede Neural¶

O código a seguir é para fazer um modelo LSTM muito simples no PyTorch. A classe LSTMTagger representa uma subclasse da classe torch.nn.Module de PyTorch para que possa obter todas as funcionalidades da classe base. Se isso é confuso para você, não se preocupe agora, apenas tente e lembre-se disso como uma convenção nas linguagens orientadas a objeto.

class LSTMTagger(torch.nn.Module):
    def __init__(self, embedding_dim, hidden_dim, vocab_size, target_size):
        # invocando o construtor da classe base
        super(LSTMTagger, self).__init__()
        # word_embeddings transformam vetores one-hot para uma representação compacta
        self.word_embeddings = torch.nn.Embedding(vocab_size, embedding_dim)
        # A lstm recebe word embeddings como entrada e gera estados ocultos de tamanho hidden_dim.
        self.lstm = torch.nn.LSTM(embedding_dim, hidden_dim)
        # hidden2tag é uma camada linear que mapeia do espaço oculto para o espaço das etiquetas. 
        self.hidden2tag = torch.nn.Linear(hidden_dim, target_size)

    def forward(self, sentence):
        embeds = self.word_embeddings(sentence)
        lstm_out, _ = self.lstm(embeds.view(len(sentence), 1, -1))
        tag_space = self.hidden2tag(lstm_out.view(len(sentence), -1))
        tag_scores = torch.nn.functional.log_softmax(tag_space, dim=1)
        return tag_scores

Acima, estabelecemos nossa classe que define o modelo neural recorrente que será utilizado: Long short-term memory (LSTM). Enquanto no construtor __init__() definimos os componentes de classe LSTMTagger, o método forward() especifica como esses componentes se relacionam.

Você deve empregar a classe LSTMTagger, disponibilizada acima, no restante deste trabalho.

def prepare_sequence(dictionary, sequence):
    num_sequence = [dictionary[item] for item in sequence]
    return torch.tensor(num_sequence, dtype=torch.long)

        num_labels = prepare_sequence(label2idx, labels).to(device)
        # Fazer a passagem dos dados pela rede (forward pass)
        pred_labels = model(num_tokens)
        # Encontrar etiqueta com maior probabilidade para cada palavra
        _, max_labels = torch.max(pred_labels, 1)
        # Computar quantas palavras são classificadas de forma correta
        bool_check = [p_label==y_label for (p_label,y_label) in zip(max_labels, num_labels)]
        # Adicionar cálculo à variável de registro
        y_true.extend(num_labels)
        y_pred.extend(max_labels)
        record.extend(bool_check)
print('Evaluation Accuracy: {}'.format(sum(record)/len(record)))
