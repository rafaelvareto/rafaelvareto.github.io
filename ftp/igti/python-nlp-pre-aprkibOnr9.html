Tokenizers¶

NLTK é uma plataforma líder para a construção de programas Python para trabalhar com dados de linguagem humana. Ele fornece interfaces fáceis de usar para mais de 50 corpora e recursos lexicais, como WordNet, junto com um pacote de bibliotecas de processamento de texto para classificação, tokenização, lematização, marcação, análise e raciocínio semântico, wrappers para bibliotecas de PNL de força industrial, e um fórum de discussão ativo.

Tokenizer de sentenças

Este tokenizer divide um texto em uma lista de frases, usando um algoritmo não supervisionado para construir um modelo para abreviações de palavras, colocações e palavras que iniciam frases.

In [ ]:
# realizando o processo de tokenização 
grande_sertao_text = "Sou só o sr. sertanejo, nessas altas ideias navego mal. Sou muito pobre coitado. Inveja minha pura é de uns conforme o senhor, com toda leitura e suma doutoração."
In [ ]:
# tokenização de sentenças em pt-br

Tokenizer de palavras

Os tokenizadores dividem as strings em listas de substrings.

Por exemplo, os tokenizadores podem ser usados para encontrar as palavras e pontuação em uma string

In [ ]:
print(sentence_list[0])

Sou só o sr. sertanejo, nessas altas ideias navego mal.
In [ ]:
# tokenizacao de palavras
from nltk.tokenize import word_tokenize
first_sentence = word_tokenize(sentence_list[0])
print(first_sentence)

['Sou', 'só', 'o', 'sr.', 'sertanejo', ',', 'nessas', 'altas', 'ideias', 'navego', 'mal', '.']

Tokenizadores de expressão regular

Um RegexpTokenizer divide uma string em substrings usando uma expressão regular. Por exemplo, o seguinte tokenizer forma tokens de sequências alfabéticas, expressões monetárias e quaisquer outras sequências que não sejam espaços em branco:

In [ ]:
# tokenização utilizando expressões regulares
from nltk.tokenize import RegexpTokenizer
regex_tker = RegexpTokenizer("[\w]+[\.]*") 
print(regex_tker.tokenize(sentence_list[0]))

['Sou', 'só', 'o', 'sr.', 'sertanejo', 'nessas', 'altas', 'ideias', 'navego', 'mal.']
In [ ]:
minas_sentence = "Bons pães de queijo custam $2.50\nem Belo Horizonte.  Por favor compre\ncinco.\n\nObrigado."

print(tokenizer.tokenize(minas_sentence))

Radical vs Lema¶

Lematização é, pois, a representação da palavra através de seu masculino singular, adjetivos e substantivos e infinitivo (verbos), apenas no contexto da lexicologia. Stemming é a retirada de sufixos do radical, enquanto stem (radical) é o próprio radical.

Análise de sentimentos¶

TextBlob visa fornecer acesso a operações comuns de processamento de texto por meio de uma interface familiar. Você pode tratar objetos TextBlob como se fossem strings de Python que aprenderam a fazer processamento de linguagem natural.

TextBlob é baseado em NLTK e fornece uma interface fácil de usar para a biblioteca NLTK. Veremos como o TextBlob pode ser usado para realizar uma variedade de tarefas de PLN, desde marcação de partes do discurso até análise de sentimento e tradução de idioma para classificação de texto. API link

In [ ]:

Obs.: A propriedade sentimento retorna uma dupla nomeada da forma Sentiment(polaridade, subjetividade). A polaridade é um ponto flutuante dentro do intervalo [-1.0, 1.0]. A subjetividade é uma flutuação dentro do intervalo [0.0, 1.0], onde 0.0 é muito objetivo e 1.0 é muito subjetivo.

TextBlob Translator¶

TextBlob é baseado em NLTK e fornece uma interface fácil de usar para a biblioteca NLTK. Veremos como o TextBlob pode ser usado para realizar uma variedade de tarefas de PLN, desde marcação de partes do discurso até análise de sentimento e tradução de idioma para classificação de texto. API link

In [ ]:

sentence_01 = u'Friendship is unnecessary, like philosophy, like art... It has no survival value; rather it is one of those things which give value to survival.'
language_translator = TextBlob(sentence_01)
result = language_translator.translate(from_lang='en', to='pt')
print(result)
print(result.sentiment)

O spaCy também permite avaliar similaridade entre palavras. O método .similarity de um Token avalia a similaridade semântica estimada entre as palavras. Quanto maior o valor, mais similar são as palavras.

In [ ]:
sentence_pt = "Mera mudança não é crescimento. Crescimento é a síntese de mudança e continuidade, e onde não há continuidade não há crescimento."
result = nlp_pt(sentence_pt)
tokens = [token for token in result]

print(tokens[1], tokens[9], tokens[1].similarity(tokens[9]))
print(tokens[11], tokens[13], result[11].similarity(result[13]))
